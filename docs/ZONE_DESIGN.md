## 0. 요약 (Executive Summary)

- A-1 유연생산 Zone을 **삼진산업 LT2 후드 Ass'y 실공정(A10~A80)** 기준의 10개 셀(C01~C10) 순차 라인으로 설계했다. 셀 배치·동선은 10/1 생기원 협의 WP6 발표자료의 라인 개념도 [S1 11쪽]를 그대로 따른다.
- 셀 사이 이송은 **고하중 전방향 AMR 12대·지그 12세트** [S4 A-1-3]가 맡고, 작업물은 지그에 실린 채 셀 도킹 위치(D)에서 처리된다. 주 이송 동선(→)과 복귀 동선(←)을 일방통행으로 분리하고, NG는 C06 → C07 재작업 → C06 재검 루프로 분기한다.
- 운영은 **레거시(AS-IS) → 자동화(기존 PLC + AMR + 룰 기반 Cell OCS) → 피지컬AI(PA Agent 기반 Cell OCS)** 3단계로 정의하고, 같은 조건 8시간 시뮬레이션으로 비교했다. 혼류(후드 2 : 도어 1)에서 레거시 18.5 UPH, 자동화 37.9 UPH, 피지컬AI 46.5 UPH (설계 추정, 가정 C/T 기준)다.
- 유연생산의 핵심 효과는 **혼류 대응력**이다. 레거시는 혼류 시 후드 단독 대비 생산량이 약 34% 떨어지고, 피지컬AI는 약 2.5%만 떨어진다(6시드 평균). 1개 단위 혼류(LOT 1)와 6초 전환을 가능하게 하는 것은 PA Agent의 레시피 선행 로딩이다.
- 도출서 KPI인 **통합 연계 작업 성공률 95% 이상** [S2 비고]은 자동화 98.7%, 피지컬AI 99.9%로 시뮬레이션 상 충족한다. 다만 C/T·이상 확률·대응 시간이 모두 가정값이므로 1차년도 실측 후 재산정이 필요하다.
- 병목은 세 단계 모두 **C03 가접·본용접(스폿용접 로봇 2대 협업)** 이다. 처리량을 더 올리려면 A-1-1(로봇 용접·접합 16대) 확장 시 C03 로봇 증설 또는 용접점 분할이 필요하다.
