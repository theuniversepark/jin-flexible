## 0. 요약 (Executive Summary)

- A-1 유연생산 Zone을 **삼진산업 LT2 후드 Ass'y 실공정(A10~A80)** 기준의 8개 공정 셀(C01~C07, C10)과 C08 출하·C09 AMR 대기·충전으로 설계했다. 셀 순서·분기는 10/1 생기원 협의 WP6 발표자료의 라인 개념도 [S1 11쪽]를 따른다.
- 시뮬레이션은 정밀조립 Zone 시뮬레이터 Jin-3D(최종 커밋 `50dccc0`)를 그대로 기반으로 삼았다. 따라서 로봇·AMR 카메라 영상, CCTV, Private 5G, VLA·AIOS, 오케스트레이터, 혼합형 다중 에이전트, 정비 휴머노이드·사족보행·드론, 입고·출하, Odoo, AAS·OPC UA·패킷 덤프가 두 Zone에서 같은 방식으로 동작한다. 바뀐 것은 Zone 정의(셀·경로·혼류·물동량)와 유연생산 고유 로직(NG 재작업 분기, 제품 전환·LOT, 통합 연계 성공률)이다.
- 배치는 jin-3d 건물(투입 왼쪽·출하 야드 오른쪽 뒤·정비실 앞쪽) 안의 **U자형**이다. 윗줄 C01→C05가 동쪽으로 흐르고, 오른쪽 통제 이송(인터록)으로 내려간다. 도어는 가운데 띠의 C10 정밀 장착을 거치고, 아랫줄 C06 검사 → C08 출하로 서쪽으로 흐른다. NG는 가운데 띠의 C07 재작업으로 분기한다.
- 3단계 비교(혼류 후드 1 : 도어 1, 4시간 × 3시드, 설계 추정)에서 UPH는 레거시 27.1 · 자동화 43.3 · 피지컬AI 59.3이다. 후드만 생산할 때 대비 생산량은 레거시 73% · 자동화 86% · 피지컬AI 99%로, **혼류 대응력**이 단계 간 핵심 차이다.
- 도출서 KPI **통합 연계 작업 성공률 95% 이상** [S2 비고]은 자동화 99.3% · 피지컬AI 99.7%로 충족한다(레거시 96.7%). 병목은 세 단계 모두 **C03 가접·본용접**이다.
- 작업 시간·이상 확률·전환 시간은 가정값이다(도출서 C/T 전부 "실측 후 산정"). 1차년도 실측 후 `js/line.js` 값만 바꿔 다시 계산한다.

### 7.2 셀 상태머신 (설계)

`IDLE → READY(도킹·클램프·ID 확인) → CHANGE(전환·드레싱) → RUN → RECOVER(L1) / HOLD(L2 대기) → DONE(완료·인계 대기) → IDLE`, 예외 `DOWN`(로봇 알람·정비), `SAFE_STOP`(비상정지·안전 PLC)

- 상태 이름은 정밀조립 WP8 V12(IDLE/READY/RUN/DONE/HOLD/RECOVER/SAFE-STOP)와 맞추고, 유연생산 특화로 CHANGE·DOWN을 추가함 [S7] [S10]

### 7.5 명령 검증 계층 [S7]

- AI가 낸 보정 명령(위치 보정량, 재용접 점수, 토출 보정률)을 작업공간·속도·힘 한계·금지영역·인터록 상태로 검사해 통과한 것만 실행함
- 거부 시 룰 기반 대체경로(재안착 등)로 감 (설계)
- 비상정지·인터락은 안전 PLC가 독립 수행하고, 플랫폼은 감시·기록만 함
